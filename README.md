# Starpointer
A device that can point to any celestial object in the sky.

No AI is used in the final versions of the project, but it has been used for ideas in designing it. The end result, including code, 3D models, and hardware choices were all created by a human.

## The plan:
Using 3D printing, a Raspberry Pi Pico 2W, an old Samsung phone, and a hell of a lot of trying to learn Onshape, I want to design a sleek, modern device that has an interactible UI and mechanically moves to point a pointer towards any celestial object, whether that be a planet, star, comet, galaxy, etc.
